Data Structures

Master lists, dictionaries, tuples, and sets for organized data management.

Module 4

Functions & Modularity

Create reusable functions, understand parameters, return values, and scope.

# Function with type hints
def calculate_total(price: float, tax: float = 0.08) -> float:
    """Calculate total price including tax."""
    return price * (1 + tax)

print(f"Total: ${calculate_total(49.99):.2f}")

Module 6

Object-Oriented Programming

Design classes, implement inheritance, and apply OOP principles.

# Class with dunder methods
class Student:
    def __init__(self, name: str, major: str):
        self.name = name
        self.major = major
    
    def __repr__(self):
        return f"Student({self.name}, {self.major})"

student = Student("Lisa", "Computer Science")
